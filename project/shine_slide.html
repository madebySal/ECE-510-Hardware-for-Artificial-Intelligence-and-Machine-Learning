① What & Why · ② Prior Work

Algorithm: Binary Neural Network (BNN) inference on MNIST [784 → 256 → 128 → 10]. Weights and activations are ±1, encoded as 1 bit.

SW baseline (CPU): 149 µs/inference  ·  6,692 samples/sec on i7-13700. Dominant kernel: Layer-1 matmul [1×784]@[784×256] accounts for >80% of runtime (FP32 NumPy — wastes 31 of every 32 bits fetched).

Prior work: FINN (Xilinx, 2017) streams BNNs on FPGAs using HLS-generated XNOR+popcount engines; BinaryConnect (Courbariaux 2015) shows <1 pp accuracy loss vs FP32 MLP on MNIST. Both target FPGAs or GPUs — no lightweight MCU-interfaced ASIC-style core.

③ What We Do Differently
  • XNOR replaces multiply — 1 gate vs ~16 in FP32
  • Popcount replaces add-tree — parallel, 1 cycle for N=784
  • Zero hardware quantization error — weights already binary
  • SPI interface for MCU edge deployment (no PCIe/AXI overhead)
  • 32× memory reduction — 25 KB vs 800 KB for W1
